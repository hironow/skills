# 実例集

各例は「入力」と、スキーマに沿った「出力」の対で示す。
出力は verdict を持たず、`flag` + `signal_strength` + `pattern_id` + `attribution` + `context_note`
に留めることを、具体で確認するためのものである。
`signal_strength` は表層シグナルの一致強度であって、「詭弁である確率」ではない。

## 1. 正しくフラグする例

著者自身が誤謬の形を主張している（`attribution: self`）ケース。

### 1-1 ストローマン（G-17）

入力:

> 「残業を減らそう」と言うが、要するに仕事を放棄して会社を潰したいわけだ。そんな主張は論外だ。

出力:

```yaml
mode: single_text
argument_frame:
  claim_type: 価値命題
  structure: []
flags:
  - pattern_id: G-17
    span: "要するに仕事を放棄して会社を潰したいわけだ"
    attribution: self
    signal_strength: 0.85
    context_note: >
      原主張「残業を減らそう」を、より極端な「仕事の放棄」に置き換えてから攻撃している。
      置き換え後の主張が原主張と一致するなら誤謬ではない。ここでは飛躍がある。
verdict: null
disclaimer: これは誤謬パターンの検出であり、詭弁の断定ではない。意図は判定していない。
```

### 1-2 人格批判（G-09）と勝利宣言（G-13）の併発

入力:

> 君は経済を専門に学んでいないのだから、その試算は聞くまでもない。この件はもう論破済みだ。

出力（要点）:

```yaml
flags:
  - pattern_id: G-09
    span: "君は経済を専門に学んでいないのだから、その試算は聞くまでもない"
    attribution: self
    signal_strength: 0.8
    context_note: 試算そのものへの反論がなく、発言者の経歴への攻撃に置き換わっている。
  - pattern_id: G-13
    span: "この件はもう論破済みだ"
    attribution: self
    signal_strength: 0.75
    context_note: 論証の実体を示さず、決着済みであることだけを宣言している。
```

### 1-3 loaded language（W-02）

入力:

> 良識ある大人なら、こんな幼稚な提案を支持したりはしない。

出力（要点）:

```yaml
flags:
  - pattern_id: W-02
    span: "良識ある大人なら / 幼稚な提案"
    attribution: self
    signal_strength: 0.7
    context_note: >
      「良識ある大人」「幼稚な」という評価語で、論理ではなく語調で結論を刷り込んでいる。
      話題が本来激しい語を要するものでないため、過剰発火の懸念は低い。
```

## 2. context_sensitive でフラグを避ける例

同じ表層でも、議論の型（`argument_frame`）が変わると正当な論法になる。

### 2-1 全称命題への反例は正当（G-02 をフラグしない）

入力:

> 「すべての白鳥は白い」と言うが、オーストラリアには黒い白鳥がいる。だからこの全称命題は偽だ。

出力:

```yaml
mode: single_text
argument_frame:
  claim_type: 全称命題
  structure: []
flags: []
verdict: null
disclaimer: これは誤謬パターンの検出であり、詭弁の断定ではない。意図は判定していない。
limitations: []
```

補足: 全称命題は反例一つで反証できる。これは G-02 ではなく、正当な反証である。

### 2-2 傾向論への単一反例は候補になる（G-02 の裏面）

入力:

> 「喫煙者は非喫煙者より早死にする傾向がある」と言うが、私の祖父は喫煙者で95歳まで生きた。だからその主張は間違いだ。

出力（要点）:

```yaml
argument_frame:
  claim_type: 傾向論
  structure: []
flags:
  - pattern_id: G-02
    span: "私の祖父は喫煙者で95歳まで生きた。だからその主張は間違いだ"
    attribution: self
    signal_strength: 0.7
    context_note: >
      統計的傾向の主張に対し、単一の例外を「主張は間違い」の根拠にしている。
      G-02 は disputed（異論あり）なので strength は控えめにし、傾向論という型に依存する点を明記する。
```

### 2-3 論理的に正しい対偶はフラグしない（W-01）

入力:

> 「雨が降れば地面が濡れる」が成り立つなら、その対偶「地面が濡れていなければ雨は降っていない」も成り立つ。

出力:

```yaml
flags: []
```

補足: 対偶変換に論理的誤りはない。ミスリードのために修辞的に使い、包含関係を因果に見せている
場合に限り、「誤謬」ではなく「ミスリード表現（category: misleading_expression）」として surface する。

## 3. 発話帰属でフラグを避ける例（最大の誤検出源）

著者が誤謬を「引用・批評」しているとき、その誤謬を著者の罪にしない。

入力:

> 彼はいつも「お前だってやっているだろう」と論点をずらしてくる。これは典型的な tu quoque であり、私の指摘への反論にはなっていない。

出力:

```yaml
mode: single_text
flags: []
verdict: null
disclaimer: これは誤謬パターンの検出であり、詭弁の断定ではない。意図は判定していない。
```

補足: 「お前だってやっている」は表層としては tu quoque（G-09 近縁）だが、`attribution: quoted` で
あり、著者はそれを**批評している側**である。著者の誤謬としてはフラグしない。
もし誰の発話かを注記したいなら、`flags` ではなく分析メモとして「引用中に tu quoque あり（著者の主張ではない）」と残す。

## 4. dialogue_log が必須の例

`requires_history: true` のパターン（G-12 蒸し返し、G-18 ずらして批難）は、単発では判定できない。

### 4-1 単発テキストでは N/A

入力（単発）:

> その話はもう決着しているはずだ。

出力:

```yaml
mode: single_text
flags: []
limitations:
  - "G-12（蒸し返し）/ G-18（ずらして批難）は会話履歴が必要なため single_text では N/A。"
```

補足: 「決着しているはず」だけでは、実際に決着済みかも、経緯を無視しているかも判定できない。
単発で無理にフラグしない。

### 4-2 履歴付きで初めて候補になる

入力（dialogue_log、抜粋）:

> A: 予算はX案で合意したよね。
> B: そうだね、合意した。
> （数ターン後）
> B: そもそも予算はX案でいいのか? 根本から考え直すべきだ。

出力（要点）:

```yaml
mode: dialogue_log
flags:
  - pattern_id: G-12
    span: "そもそも予算はX案でいいのか? 根本から考え直すべきだ"
    attribution: self
    signal_strength: 0.7
    context_note: >
      直前に B 自身が合意した論点を、経緯を無視して再提起している。
      新しい根拠が提示されているなら再検討は正当なので、根拠の有無を確認する。
```

## 5. 自己適用（反証可能性）で降格する例

チェッカー自身が後件肯定（S-02）に陥りかける典型。Stage 3 で降格する。

チェッカーの内心（誤り）:

> このテキストは「もし〜だったら」という仮定を持ち出している。詭弁には仮定の持ち出し（G-01）がある。だからこれは詭弁だ。

Stage 3 で問う: この span を誤謬たらしめる frame は何か。

着地（正しい出力）:

```yaml
flags:
  - pattern_id: G-01
    span: "もし〜だったら"
    attribution: self
    signal_strength: 0.4
    context_note: >
      G-01 の表層（未検証の仮定の対置）に一致する。ただし、対置先が「確定した事実」で
      あるかは文脈依存であり、ここでは確定していない。探索のための仮定なら正当。
      よってフラグは弱く、verdict は出さない。
verdict: null
```

補足: 「特徴（仮定の持ち出し）があるから詭弁だ」は、まさに後件肯定（S-02）である。
frame（確定事実への対置かどうか）を明示できない限り、断定せず弱いフラグに留める。
