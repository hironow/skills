# 座席の保証の条件を、元の格子の外で確かめる

検査の手順は [check.py](check.py)、結果は [results.tsv](results.tsv) にある。

## 結論

**条件は、値の範囲を広げても、顧客を 3 人にしても、すべての設定で検査の結果と一致した。**

条件: 「返金された顧客はいない」が成り立つのは、決済を始めたときの延長が、
決済サービスの最大の応答時間以上のとき。停止中に仮確保の時計を止めないなら、
さらに停止の最大の長さを足す。

| 検査 | 設定の数 | 条件と一致 |
|---|---|---|
| 元の格子 (規模の実験 003)。顧客 2 人 | 288 | 288 |
| 値を広げた格子。有効期間 1, 3、延長 0〜5、応答 1〜4、停止 0〜3。顧客 2 人 | 768 | 768 |
| 元の格子。顧客 3 人 | 288 | 288 |

どの設定も、TLC で全状態を調べた。状態数は最大で 363 だった。

## 限界

- これは有限の設定を調べた結果で、任意の値についての証明ではない。
- 座席は 1 つのままである。座席を増やした場合は調べていない。
- 条件そのものは、道具を使わないモデルも導いた ([導出の実験 006](../derive-006/result.md))。
  ここで足したのは、条件が 1344 通りの設定で正しいという確認である。
