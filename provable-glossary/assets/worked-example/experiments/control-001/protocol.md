# 対照実験 001: 形式手法なしで、同じ空白は見つかるか

## 問い

`docs/findings.md` の発見は、Lean と Quint がなければ見つからなかったのか。

## やり方

1. 形式手法の側の発見を 24 件の採点対象として固定する ([targets.md](targets.md))。
   各対象に、元の議論にすでにあった (D) か、形式手法の作業で初めて出た (N) かの印を付ける。
2. 対照には、業務の説明と出発点の用語集だけを渡す ([input.md](input.md))。
   元の議論の分析も、この実験の発見も渡さない。道具はすべて切る。
3. 対照は 3 回。モデルを変える (Fable 5.2, Opus 5.5, Sonnet 5.5)。
   空のディレクトリで、ツールなし、設定なしで 1 回ずつ実行する。
4. 採点は別の文脈の採点者が行う。各対象について、見つけた (2)、触れたが要点を外した (1)、
   なし (0) を付け、根拠の番号を示す。私が抜き取りで確かめる。
5. 対照だけが挙げた項目も数える。形式手法の側が見落としたものである。

## 実行前の予想

- 対照は 24 件のうち 7 割以上を見つける。D の対象はほぼ全部見つける。
- N のうち、T22 (復旧への依存) と T23 (両立しない要求) は見つけにくい。
- 対照は、形式手法の側が扱わなかった項目を 10 件以上挙げる
  (決済の失敗や通知の重複、顧客への連絡、会計など)。

## 結論の決め方

- N の対象を対照 3 回のうち 2 回以上が見つけたら、その発見に形式手法は要らなかったと判定する。
- N の対象の過半が要らなかったなら、「発見の道具としての価値は示せなかった」と結論する。

## 限界

- 対照のモデルは、形式手法の側を実行したモデルと同じ系列である。人間の対照ではない。
- 採点対象は形式手法の側が作ったので、形式手法の側に有利である。
  そのため、対照だけが挙げた項目を別に数える。
- 入力の文章は私が書いた。場面の説明そのものが手がかりになりうる。
- 各モデル 1 回なので、ばらつきは測れない。
