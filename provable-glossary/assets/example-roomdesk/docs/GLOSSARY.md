# roomdesk 用語集

運営チームが管理しています。最終更新: 2025 年 4 月。

| 用語 | 定義 |
|---|---|
| 会員 | 予約を行う利用者 |
| 会議室 | 貸し出す部屋 |
| 時間枠 | 会議室を貸し出す 1 時間の単位 |
| 予約 | 会員が仮押さえを経て時間枠を確保したもの |
| 仮押さえ | 予約が確定するまで、時間枠を 15 分間確保すること |
| 仮押え | 決済の前に時間枠を一時的に確保すること |
| 決済 | 予約の料金をカードで支払うこと |
| 予約確定 | 決済が完了した予約 |
| 回数券 | 10 回分の予約をまとめて購入できる券 |
| 閉鎖 | 設備の都合で時間枠を使えなくすること |
| 返金 |  |
| 受付停止 | 不正アクセスの検知時に、システムが予約の受付を止めること |
